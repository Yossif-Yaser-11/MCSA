Nano Server

شرح نظري وتطبيق عملي لإدارة Windows Server.

العودة إلى فهرس الدروس

الـ Nano Server هو إصدار خفيف جداً من Windows Server مصمم للـ Cloud والـ Containers. حجمه صغير جداً (جزء من 1GB) ومش فيه واجهة رسومية ومش بيدعم تسجيل الدخول المحلى.

مميزات Nano Server

  • حجم صغير جداً - أقل سطح للهجوم (Attack Surface)
  • إعادة تشغيل أسرع
  • تحديثات أقل - وقت Downtime أقل
  • مثالى للـ Containers والـ Microservices
  • استهلاك موارد منخفض

قيود Nano Server

  • لا يدعم الاتصال المحلى (Console) - فقط عن بعد
  • لا يدعم معظم الـ GUI Tools
  • قائمة محدودة من الـ Roles المدعومة
  • الإدارة بالـ PowerShell فقط أو WMI

إنشاء Nano Server Image

# بيتطلب Windows Server 2016 ISO
# استيراد الـ NanoServerImageGenerator Module
Import-Module "E:\NanoServer\NanoServerImageGenerator.psm1"

# إنشاء Image للـ Hyper-V
New-NanoServerImage `
    -MediaPath "E:\" `
    -BasePath "C:\NanoBase" `
    -TargetPath "C:\NanoImages\NanoHyperV.vhdx" `
    -DeploymentType Guest `
    -Edition Datacenter `
    -ComputerName "NANO-HV01" `
    -AdministratorPassword (ConvertTo-SecureString "Nano@Admin123" -AsPlainText -Force) `
    -Packages Microsoft-NanoServer-Compute-Package `
    -DomainName "networkat.local" `
    -JoinDomain "networkat.local" `
    -StaticIPv4Address "192.168.1.50" `
    -StaticIPv4Gateway "192.168.1.1" `
    -StaticIPv4DNS "192.168.1.10"

إدارة Nano Server عن بعد

# الاتصال بالـ PowerShell
Enter-PSSession -ComputerName "NANO-HV01" -Credential (Get-Credential)

# أو بـ WinRM
$session = New-PSSession -ComputerName "NANO-HV01"
Invoke-Command -Session $session -ScriptBlock {Get-Process}

# Emergency Management Services (EMS)
# لو الشبكة وقعت، تتصل عبر Serial Port

التطبيق العملى - Nano Server

تمرين 1: إنشاء Nano Server Image

# Mount الـ ISO
Mount-DiskImage -ImagePath "C:\WS2016.iso"
$drive = (Get-DiskImage "C:\WS2016.iso" | Get-Volume).DriveLetter

# استيراد الـ Module
Import-Module "$($drive):\NanoServer\NanoServerImageGenerator.psm1"

# إنشاء Image بسيطة للـ IIS
$pass = ConvertTo-SecureString "Nano@Pass123" -AsPlainText -Force
New-NanoServerImage `
    -MediaPath "$($drive):\" `
    -BasePath "C:\NanoBase" `
    -TargetPath "C:\NanoImages\NanoWeb.vhdx" `
    -DeploymentType Guest `
    -Edition Standard `
    -ComputerName "NANO-WEB01" `
    -AdministratorPassword $pass `
    -Packages Microsoft-NanoServer-IIS-Package `
    -StaticIPv4Address "192.168.1.60" `
    -StaticIPv4Gateway "192.168.1.1" `
    -StaticIPv4DNS "192.168.1.10"

تمرين 2: الاتصال وإدارة Nano Server

# إضافة الـ IP لـ TrustedHosts
Set-Item WSMan:\localhost\Client\TrustedHosts "192.168.1.60" -Force

# الاتصال
$cred = Get-Credential "Administrator"
Enter-PSSession -ComputerName "192.168.1.60" -Credential $cred
