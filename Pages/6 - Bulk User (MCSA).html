Bulk User Creation فى Active Directory

شرح نظري وتطبيق عملي لإدارة Windows Server.

العودة إلى فهرس الدروس

فى الشركات الكبيرة، ممكن تحتاج تنشئ مئات أو آلاف الـ Users فى وقت واحد. الـ Bulk Creation بيوفّر وقت ومجهود ضخم.

طرق الـ Bulk Creation

  • CSV + PowerShell: الأسهل والأشمل - بتجهز ملف Excel وبتشغّله
  • LDIFDE: أداة سطر أوامر - بتستخدم ملفات LDIF
  • CSVDE: أداة سطر أوامر - بتستخدم ملفات CSV مباشرة
  • AD Administrative Center: واجهة رسومية - للعمليات الفردية

Bulk Import بـ CSV و PowerShell

خطوة 1: تجهيز ملف CSV

Name,SamAccountName,GivenName,Surname,Department,Title,Email
Ahmed Ali,ahmed.ali,Ahmed,Ali,IT,Engineer,ahmed.ali@networkat.local
Sara Omar,sara.omar,Sara,Omar,HR,Manager,sara.omar@networkat.local
Mohamed Khaled,mohamed.khaled,Mohamed,Khaled,Finance,Accountant,m.khaled@networkat.local

خطوة 2: Script الاستيراد

$users = Import-Csv -Path "C:\Users.csv"
$defaultPassword = ConvertTo-SecureString "Welcome@2024" -AsPlainText -Force
foreach ($user in $users) {    
    try {        
        $ouPath = "OU=Users,OU=$($user.Department)_Department,DC=networkat,DC=local"                
        New-ADUser `            
            -Name $user.Name `            
            -SamAccountName $user.SamAccountName `            
            -UserPrincipalName "$($user.SamAccountName)@networkat.local" `            
            -GivenName $user.GivenName `            
            -Surname $user.Surname `            
            -Department $user.Department `            
            -Title $user.Title `            
            -EmailAddress $user.Email `            
            -Path $ouPath `            
            -AccountPassword $defaultPassword `            
            -Enabled $true `            
            -ChangePasswordAtLogon $true                
        Write-Host "✅ Created: $($user.Name)" -ForegroundColor Green    
    }    
    catch {        
        Write-Host "❌ Error creating $($user.Name): $($_.Exception.Message)" -ForegroundColor Red    
    }
}
Write-Host "Import Complete!"

Bulk Export

# Export كل الـ Users لـ CSV
Get-ADUser -Filter * -Properties Department,Title,EmailAddress | `    
    Select Name,SamAccountName,Department,Title,EmailAddress,Enabled | `    
    Export-Csv -Path "C:\AD_Users_Export.csv" -NoTypeInformation

# Export Users من Department معين
Get-ADUser -Filter {Department -eq "IT"} -Properties Department | `    
    Select Name,SamAccountName,Department | `    
    Export-Csv -Path "C:\IT_Users.csv" -NoTypeInformation

التطبيق العملى - Bulk Operations

تمرين 1: استيراد Users من CSV

  1. اعمل ملف CSV على Desktop باسم users.csv
  2. حط فيه 10 Users من أقسام مختلفة
  3. شغّل الـ Script اللى فوق
  4. تحقق من الـ AD إن الـ Users اتعملوا

تمرين 2: Bulk Disable Users

# تعطيل كل Users قسم معين
Get-ADUser -Filter {Department -eq "Resigned"} | Disable-ADAccount

# تعطيل Users من CSV
$users = Import-Csv "C:\resigned_users.csv"
$users | ForEach-Object {    
    Disable-ADAccount -Identity $_.SamAccountName    
    Write-Host "Disabled: $($_.Name)"
}

تمرين 3: Bulk Password Reset

# Reset كلمة سر لـ Group معينة
$groupMembers = Get-ADGroupMember -Identity "GG_New_Employees"
$newPassword = ConvertTo-SecureString "TempPass@123" -AsPlainText -Force

foreach ($member in $groupMembers) {    
    Set-ADAccountPassword -Identity $member.SamAccountName -Reset -NewPassword $newPassword    
    Set-ADUser -Identity $member.SamAccountName -ChangePasswordAtLogon $true    
    Write-Host "Password reset for: $($member.Name)"
}
