Group Policy - الجزء الأول

شرح نظري وتطبيق عملي لإدارة Windows Server.

العودة إلى فهرس الدروس

الـ Group Policy هى من أقوى أدوات إدارة Windows Server. بتخليك تطبّق إعدادات موحدة على آلاف الأجهزة والمستخدمين من مكان واحد.

ما الذى يمكن إدارته بالـ Group Policy؟

  • إعدادات الأمان (Password Policy, Lockout, Firewall)
  • تثبيت وتوزيع البرامج تلقائياً
  • إعدادات الـ Desktop وـ Start Menu
  • تقييد الوصول لبعض البرامج أو الإعدادات
  • تعيين الـ Drive Mapping تلقائياً
  • إعدادات الـ Internet Explorer / Edge
  • Scripts تشتغل عند الـ Logon / Logoff / Startup / Shutdown

بنية الـ Group Policy

  • GPO (Group Policy Object): الوعاء اللى فيه الإعدادات
  • GPMC (Group Policy Management Console): الأداة لإدارة الـ GPOs
  • GPO Link: ربط الـ GPO بـ Site أو Domain أو OU

ترتيب تطبيق الـ Group Policy (LSDOU)

  1. L - Local: الـ GPO المحلى على الجهاز نفسه
  2. S - Site: الـ GPO المربوط بالـ AD Site
  3. D - Domain: الـ GPO المربوط بالـ Domain
  4. OU: الـ GPO المربوط بالـ OU (الأحدث يغلب)

الـ GPO الأخير اللى بيتطبق هو اللى بيأثر فعلياً. يعنى الـ OU GPO بيغلب الـ Domain GPO.

إنشاء وإدارة GPO

# إنشاء GPO جديد
New-GPO -Name "Security_Policy" -Domain "networkat.local"

# ربط الـ GPO بـ OU
New-GPLink -Name "Security_Policy" -Target "OU=IT_Department,DC=networkat,DC=local"

# تطبيق إعداد معين
Set-GPRegistryValue -Name "Security_Policy" -Key "HKLM\Software\Policies" -ValueName "Setting" -Type DWORD -Value 1

# تفعيل/تعطيل GPO
Set-GPLink -Name "Security_Policy" -Target "OU=IT_Department,DC=networkat,DC=local" -LinkEnabled Yes

أوامر مهمة

# تحديث الـ Group Policy على الجهاز
gpupdate /force

# عرض الـ GPOs المطبقة على الجهاز الحالى
gpresult /r

# عرض تقرير تفصيلى
gpresult /h "C:\GPReport.html" && start "C:\GPReport.html"

التطبيق العملى - Group Policy الجزء الأول

تمرين 1: Password Policy

# Password Policy على الـ Default Domain Policy
$gpo = Get-GPO -Name "Default Domain Policy"
Set-GPRegistryValue -Guid $gpo.Id -Key "HKLM\SYSTEM\CurrentControlSet\Services\Netlogon\Parameters" -ValueName "MaximumPasswordAge" -Type DWORD -Value 90

# أو من الـ GUI
# 1. افتح Group Policy Management
# 2. Forests → Domains → networkat.local → Default Domain Policy
# 3. Edit → Computer Configuration → Windows Settings → Security Settings → Account Policies → Password Policy
# 4. عدّل الإعدادات

تمرين 2: تثبيت برنامج تلقائياً

# إنشاء GPO لتوزيع برنامج
New-GPO -Name "Deploy_Chrome"

# مشاركة مجلد الـ Software
New-SmbShare -Name "Software" -Path "D:\Software" -ReadAccess "Domain Computers"

# نسخ الـ MSI للمجلد
Copy-Item "C:\GoogleChrome.msi" "D:\Software\"

# من الـ GUI:
# Computer Configuration → Software Settings → Software Installation
# New → Package → \\SRV-DC01\Software\GoogleChrome.msi → Assigned

تمرين 3: Logon Script

# إنشاء Script
$script = @"
net use H: \\SRV-File\HR$ /persistent:yes
nets use I: \\SRV-File\IT$ /persistent:yes
"@
$script | Out-File "\\networkat.local\SYSVOL\networkat.local\Policies\Scripts\logon.bat"

# ربطه بـ GPO
# User Configuration → Windows Settings → Scripts → Logon → Add
