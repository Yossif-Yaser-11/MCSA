Disk Quota - تحديد حصة المستخدمين

شرح نظري وتطبيق عملي لإدارة Windows Server.

العودة إلى فهرس الدروس

الـ Disk Quota بيخليك تتحكم فى حجم المساحة اللى كل مستخدم يقدر يستخدمها على السيرفر. بيمنع مستخدم واحد من ملء القرص كله.

أنواع الـ Quota

النوعالوصف
Volume Quotaبيطبّق على كل الـ Volume - الكلاسيكى
FSRM QuotaFile Server Resource Manager - أكثر مرونة وتحكماً

إعداد Volume Quota

# من الـ GUI
1. افتح My Computer
2. كليك يمين على الـ Drive → Properties
3. تاب Quota → Enable Quota Management
4. حدد الـ Default Limit
5. حدد الـ Warning Level

# من PowerShell (لازم FSRM مثبت)
Install-WindowsFeature -Name FS-Resource-Manager -IncludeManagementTools

FSRM Quota - الأقوى والأمثل

# إنشاء Quota Template
New-FsrmQuotaTemplate -Name "5GB User Quota" `
    -Size 5GB `
    -SoftLimit $false `
    -Threshold @(
        New-FsrmQuotaThreshold -Percentage 80 -Action @(
            New-FsrmAction Email -MailTo "[Admin Email]" -Subject "Quota Warning" -Body "User [Quota Path Owner] reached 80% of quota on [Quota Path]"
        ),
        New-FsrmQuotaThreshold -Percentage 100
    )

# تطبيق الـ Quota على مجلد
New-FsrmQuota -Path "D:\Users\ahmed" -Template "5GB User Quota"

# تطبيق تلقائى على مجلدات المستخدمين
New-FsrmAutoQuota -Path "D:\Users" -Template "5GB User Quota" -Enabled $true

File Screening - منع أنواع ملفات معينة

# منع رفع ملفات الـ Media
New-FsrmFileScreenTemplate -Name "Block Audio Video" `
    -IncludeGroup @("Audio and Video Files") `
    -Active $true

New-FsrmFileScreen -Path "D:\Company_Data" -Template "Block Audio Video"

# عرض الـ Quotas الحالية
Get-FsrmQuota -Path "D:\Users" | Select Path, Size, Usage, PeakUsage

التطبيق العملى - Disk Quota

تمرين 1: تثبيت وإعداد FSRM

Install-WindowsFeature -Name FS-Resource-Manager -IncludeManagementTools

# إعداد SMTP للإشعارات
Set-FsrmSetting -SmtpServer "mail.networkat.local" -AdminEmailAddress "admin@networkat.local" -FromEmailAddress "server@networkat.local"

تمرين 2: Quota لكل المستخدمين

# إنشاء Templates مختلفة
New-FsrmQuotaTemplate -Name "Standard User 5GB" -Size 5GB -SoftLimit $false
New-FsrmQuotaTemplate -Name "Power User 20GB" -Size 20GB -SoftLimit $false
New-FsrmQuotaTemplate -Name "Warning Only 10GB" -Size 10GB -SoftLimit $true

# تطبيق تلقائى
New-FsrmAutoQuota -Path "D:\Users" -Template "Standard User 5GB" -Enabled $true

# تطبيق Quota مخصص على User معين
New-FsrmQuota -Path "D:\Users\Manager" -Template "Power User 20GB"

# التحقق
Get-FsrmQuota | Select Path, @{N="Size(GB)";E={$_.Size/1GB}}, @{N="Usage(GB)";E={[math]::Round($_.Usage/1GB,2)}}

تمرين 3: File Screening

# منع الـ Executables والـ Media فى مجلد الشركة
New-FsrmFileScreenTemplate -Name "Company Policy" -IncludeGroup @("Executable Files","Audio and Video Files") -Active $true
New-FsrmFileScreen -Path "D:\Company_Data" -Template "Company Policy"

# مشاهدة تقارير الـ Storage
Start-FsrmStorageReport -Name "User Quota Report" -Path "D:\Users" -ReportType QuotaUsage
