GPO Filtering - التحكم فى من يطبّق الـ GPO

مش كل الـ GPO لازم يطبّق على كل الأجهزة والمستخدمين. فيه طريقتين للتحكم:

Security Filtering

بتحدد مين يستقبل الـ GPO - Users أو Groups أو Computers:

# إزالة Authenticated Users الافتراضى
Set-GPPermissions -Name "IT_Policy" -TargetName "Authenticated Users" -TargetType Group -PermissionLevel None

# إضافة Group معين
Set-GPPermissions -Name "IT_Policy" -TargetName "GG_IT_Staff" -TargetType Group -PermissionLevel GpoApply

WMI Filtering

بتطبّق الـ GPO بناءً على خصائص الجهاز (نوع الـ Windows، مقدار الـ RAM، إلخ):

# WMI Filter - يطبّق فقط على Windows 10
New-GPWmiFilter -Name "Win10_Only" -Expression "SELECT * FROM Win32_OperatingSystem WHERE Version LIKE "10.0%"" -Domain "networkat.local"

GPO Inheritance

الـ GPOs بتنتقل من الـ Parent للـ Child OUs. ممكن تتحكم فى الـ Inheritance:

  • Block Inheritance: يمنع الـ GPOs من الـ Parent من الوصول للـ OU ده
  • Enforced (No Override): يجبر الـ GPO يطبّق حتى لو الـ Child عمل Block
# Block Inheritance على OU
Set-GPInheritance -Target "OU=Special,DC=networkat,DC=local" -IsBlocked Yes

# Enforce GPO
$link = Get-GPLink -Name "Domain_Security" -Target "DC=networkat,DC=local"
Set-GPLink -Guid $link.GpoId -Target "DC=networkat,DC=local" -Enforced Yes

Group Policy Preferences

الـ Preferences أقوى من الـ Policies فى بعض الجوانب - بتدّى المستخدم حرية تغيير الإعداد بعد تطبيقه:

  • Drive Maps: تعيين Network Drives تلقائياً
  • Printers: إضافة طابعات
  • Registry: تعديل الـ Registry
  • Files/Folders: إنشاء وتوزيع ملفات
  • Environment Variables: متغيرات البيئة
# Drive Mapping عبر GPO Preferences
# User Configuration → Preferences → Windows Settings → Drive Maps
# New → Mapped Drive
# Action: Create
# Location: \\SRV-File\HR$
# Drive Letter: H
# Label: HR Department Data

التطبيق العملى - Group Policy الجزء الثانى

تمرين 1: GPO للأمان

# إنشاء Security GPO
New-GPO -Name "Workstation_Security"

# تطبيق إعدادات أمان
# من الـ GUI: Computer Configuration → Windows Settings → Security Settings

# إعدادات مهمة:
# 1. Account Lockout: 5 محاولات → Lock 30 دقيقة
# 2. Audit Policy: تسجيل كل Logon Success/Failure
# 3. User Rights: منع تسجيل الدخول محلياً للـ Guests
# 4. Security Options: تعطيل Anonymous Access

# ربط بالـ Domain
New-GPLink -Name "Workstation_Security" -Target "DC=networkat,DC=local"

تمرين 2: Drive Mapping بـ GPO Preferences

# إنشاء GPO للـ Drive Mapping
New-GPO -Name "Drive_Mapping"
New-GPLink -Name "Drive_Mapping" -Target "DC=networkat,DC=local"

# من الـ GUI:
# User Config → Preferences → Windows Settings → Drive Maps
# Map H: → \\SRV-File\HR$ (للـ HR Group فقط)
# Map I: → \\SRV-File\IT$ (للـ IT Group فقط)
# استخدم Item-Level Targeting لتطبيق على Groups معينة

تمرين 3: Troubleshooting GPO

# التحقق من الـ GPOs المطبقة
gpresult /r /scope computer
gpresult /r /scope user

# تقرير HTML تفصيلى
gpresult /h "C:\GPReport.html"

# تحديث الـ GPO فوراً
gpupdate /force /boot /logoff

# التحقق من الـ SYSVOL
ls \\networkat.local\SYSVOL\networkat.local\Policies
