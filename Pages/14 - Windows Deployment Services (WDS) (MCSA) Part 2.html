WDS - الجزء الثانى - Answer Files و Customization

شرح نظري وتطبيق عملي لإدارة Windows Server.

العودة إلى فهرس الدروس

الـ Answer File (Unattend.xml) بيخليك تعمل تثبيت تلقائى كامل بدون ما تتدخل يدوياً. كل الإعدادات (اسم الجهاز، كلمة السر، الـ Domain) بتتحدد مسبقاً.

Windows System Image Manager (WSIM)

الأداة الرسمية من Microsoft لإنشاء الـ Answer Files. بتجيها مع الـ Windows ADK.

مراحل الـ Answer File

المرحلةالتوقيتالاستخدام
windowsPEأول التثبيتإعدادات القرص واللغة
offlineServicingبعد النسخإضافة Drivers والـ Updates
specializeأثناء التخصيصاسم الجهاز، انضمام الـ Domain
oobeSystemأول تشغيلالمستخدم، كلمة السر، الـ Timezone

مثال Answer File بسيط

<?xml version="1.0" encoding="utf-8"?>
<unattend xmlns="urn:schemas-microsoft-com:unattend">
  <settings pass="specialize">
    <component name="Microsoft-Windows-Shell-Setup">
      <ComputerName>SRV-NEW</ComputerName>
      <RegisteredOrganization>Networkat</RegisteredOrganization>
    </component>
    <component name="Microsoft-Windows-UnattendedJoin">
      <Identification>
        <JoinDomain>networkat.local</JoinDomain>
        <Credentials>
          <Domain>networkat.local</Domain>
          <Username>Administrator</Username>
          <Password>Admin@Pass123</Password>
        </Credentials>
      </Identification>
    </component>
  </settings>
  <settings pass="oobeSystem">
    <component name="Microsoft-Windows-Shell-Setup">
      <AutoLogon>
        <Password><Value>Admin@Pass123</Value></Password>
        <Username>Administrator</Username>
        <LogonCount>1</LogonCount>
        <Enabled>true</Enabled>
      </AutoLogon>
    </component>
  </settings>
</unattend>

ربط Answer File بـ WDS

# ربط Answer File بالـ Install Image
Set-WdsInstallImage -ImageName "WS2016 Standard" -ImageGroup "Windows Server 2016" -UnattendFile "C:\Unattend.xml"

# أو ربط بـ Computer Group معين
New-WdsClient -DeviceID "MAC:00-11-22-33-44-55" -DeviceName "SRV-NEW" -JoinDomain $true -PxePromptPolicy OptOut -WdsClientUnattend "C:\Unattend.xml"

التطبيق العملى - WDS Answer Files

تمرين 1: تثبيت Windows ADK

  1. حمّل Windows ADK من موقع Microsoft
  2. ثبّت Deployment Tools و Windows PE
  3. افتح Windows System Image Manager (WSIM)
  4. افتح ملف catalog من الـ ISO (sources\install.wim)

تمرين 2: إنشاء Answer File

# بعد إنشاء الـ Unattend.xml من WSIM
# اختبار الـ Answer File
C:\Windows\System32\sysprep\sysprep.exe /oobe /generalize /unattend:C:\Unattend.xml

# رفع الـ Answer File لـ WDS
Copy-Item "C:\Unattend.xml" "D:\RemoteInstall\WdsClientUnattend\WS2016_Unattend.xml"

تمرين 3: Capture Image (من جهاز جاهز)

# لو عندك جهاز معمول عليه الإعدادات، تقدر تعمل Capture
# 1. على الجهاز المصدر: Sysprep أولاً
C:\Windows\System32\sysprep\sysprep.exe /oobe /generalize /shutdown

# 2. Boot الجهاز من WDS
# 3. اختار Capture Image بدل Install
# 4. احفظ الـ Image على الـ WDS Server
# 5. استخدمه لتثبيت نفس الـ Setup على أجهزة كتير
