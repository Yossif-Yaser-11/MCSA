iSCSI - Internet Small Computer System Interface

شرح نظري وتطبيق عملي لإدارة Windows Server.

العودة إلى فهرس الدروس

الـ iSCSI بيخليك توصّل بـ Storage بعيد عبر شبكة Ethernet العادية وتتعامل معاه كأنه قرص محلى. بديل اقتصادى للـ Fiber Channel SAN.

مكونات iSCSI

  • iSCSI Target: السيرفر اللى بيقدّم الـ Storage
  • iSCSI Initiator: العميل اللى بيتصل بالـ Storage
  • LUN (Logical Unit Number): وحدة الـ Storage المشتركة
  • IQN (iSCSI Qualified Name): معرّف فريد لكل Target/Initiator

إعداد iSCSI Target على Windows Server

# تثبيت الـ Role
Install-WindowsFeature -Name FS-iSCSITarget-Server -IncludeManagementTools

# إنشاء iSCSI Virtual Disk
New-IscsiVirtualDisk -Path "C:\iSCSI\DataLUN.vhdx" -Size 100GB

# إنشاء Target
New-IscsiServerTarget -TargetName "DataTarget" -InitiatorIds @("IPAddress:192.168.1.50")

# ربط الـ LUN بالـ Target
Add-IscsiVirtualDiskTargetMapping -TargetName "DataTarget" -Path "C:\iSCSI\DataLUN.vhdx"

إعداد iSCSI Initiator على Windows

# تشغيل الـ iSCSI Initiator Service
Start-Service MSiSCSI
Set-Service MSiSCSI -StartupType Automatic

# الاتصال بالـ Target
$target = New-IscsiTargetPortal -TargetPortalAddress "192.168.1.10"
Get-IscsiTarget | Connect-IscsiTarget -IsPersistent $true

# هيّئه وأضفله Drive Letter عادى

MPIO - Multipath I/O

الـ MPIO بيخليك تتصل بالـ Storage عبر أكتر من مسار - زيادة الأداء والـ Redundancy:

Install-WindowsFeature -Name Multipath-IO
Enable-MSDSMAutomaticClaim -BusType iSCSI

التطبيق العملى - iSCSI

تمرين 1: إعداد iSCSI Target Server

# على SRV-Storage
Install-WindowsFeature -Name FS-iSCSITarget-Server -IncludeManagementTools

# إنشاء مجلد للـ LUNs
New-Item -Path "C:\iSCSI_LUNs" -ItemType Directory

# إنشاء Virtual Disk
New-IscsiVirtualDisk -Path "C:\iSCSI_LUNs\SQL_LUN.vhdx" -Size 50GB
New-IscsiVirtualDisk -Path "C:\iSCSI_LUNs\Exchange_LUN.vhdx" -Size 100GB

# إنشاء Targets
New-IscsiServerTarget -TargetName "SQL-Target" -InitiatorIds @("IPAddress:192.168.1.20")
New-IscsiServerTarget -TargetName "Exchange-Target" -InitiatorIds @("IPAddress:192.168.1.30")

# ربط الـ LUNs
Add-IscsiVirtualDiskTargetMapping -TargetName "SQL-Target" -Path "C:\iSCSI_LUNs\SQL_LUN.vhdx"
Add-IscsiVirtualDiskTargetMapping -TargetName "Exchange-Target" -Path "C:\iSCSI_LUNs\Exchange_LUN.vhdx"

تمرين 2: الاتصال من Client

# على SRV-SQL (Initiator)
Start-Service MSiSCSI
Set-Service MSiSCSI -StartupType Automatic

# الاتصال بالـ Target
New-IscsiTargetPortal -TargetPortalAddress "192.168.1.10"
$target = Get-IscsiTarget | Where-Object {$_.NodeAddress -like "*SQL*"}
$target | Connect-IscsiTarget -IsPersistent $true

# تهيئة الـ Disk الجديد
Get-Disk | Where-Object PartitionStyle -eq Raw | Initialize-Disk -PartitionStyle GPT
New-Partition -DiskNumber 2 -UseMaximumSize -DriveLetter F
Format-Volume -DriveLetter F -FileSystem NTFS -NewFileSystemLabel "SQL_Data" -Confirm:$false
