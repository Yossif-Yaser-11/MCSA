Routing فى Windows Server

شرح نظري وتطبيق عملي لإدارة Windows Server.

العودة إلى فهرس الدروس

Windows Server بيقدر يشتغل كـ Router بين الشبكات المختلفة باستخدام خدمة RRAS (Routing and Remote Access Service).

RRAS - Routing and Remote Access Service

الـ RRAS بيوفّر:

  • IP Routing: توجيه الـ Traffic بين الشبكات
  • NAT: ترجمة العناوين للإنترنت
  • VPN Server: اتصالات VPN للموظفين عن بعد
  • Dial-Up: اتصالات قديمة (نادرة)

تثبيت وإعداد RRAS

# تثبيت الـ Role
Install-WindowsFeature -Name RemoteAccess -IncludeManagementTools
Install-WindowsFeature -Name RSAT-RemoteAccess-Mgmt

# تفعيل الـ Routing
Install-RemoteAccess -VpnType RoutingOnly

# تفعيل IP Forwarding
Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Services\Tcpip\Parameters" -Name "IPEnableRouter" -Value 1

Static Routes فى Windows

# إضافة Static Route
Route Add 10.0.0.0 MASK 255.0.0.0 192.168.1.1

# Route دائمة (بتفضل بعد الـ Restart)
Route Add 10.0.0.0 MASK 255.0.0.0 192.168.1.1 -P

# عرض جدول الـ Routing
Route Print
Get-NetRoute

# حذف Route
Route Delete 10.0.0.0

NAT على Windows Server

# تفعيل NAT عبر RRAS GUI
1. افتح Routing and Remote Access
2. IPv4 → NAT
3. كليك يمين → New Interface
4. اختار الـ Interface الخارجى (Internet)
5. فعّل NAT على الـ Public Interface

VPN Server إعداد مبسط

# إعداد VPN Server
Install-RemoteAccess -VpnType VpnS2S

# إضافة VPN User
Add-VpnUser -UserName "vpnuser" -Password "VPN@Pass123"

# فتح Ports على الـ Firewall
New-NetFirewallRule -DisplayName "PPTP VPN" -Direction Inbound -Protocol TCP -LocalPort 1723 -Action Allow
New-NetFirewallRule -DisplayName "L2TP VPN" -Direction Inbound -Protocol UDP -LocalPort 1701 -Action Allow
New-NetFirewallRule -DisplayName "SSTP VPN" -Direction Inbound -Protocol TCP -LocalPort 443 -Action Allow

التطبيق العملى - Routing

تمرين 1: إعداد RRAS Router

# السيرفر بيه Interfaceين:
# Gi1: 192.168.1.1/24 (LAN)
# Gi2: 10.0.0.1/30 (WAN للـ Router التانى)

Install-WindowsFeature -Name RemoteAccess, RSAT-RemoteAccess-Mgmt -IncludeManagementTools
Install-RemoteAccess -VpnType RoutingOnly

# إضافة Static Route
Add-NetRoute -DestinationPrefix "172.16.0.0/16" -NextHop "10.0.0.2" -InterfaceAlias "Ethernet 2"

# التحقق
Get-NetRoute | Where-Object {$_.DestinationPrefix -ne "0.0.0.0/0"} | Select DestinationPrefix, NextHop, InterfaceAlias

تمرين 2: NAT للإنترنت

# فى Routing and Remote Access (GUI)
# 1. كليك يمين على IPv4 → NAT
# 2. New Interface → اختار Gi2 (الإنترنت)
# 3. Public interface connected to the Internet
# 4. Enable NAT on this interface
# 5. Gi1 (LAN) → Private interface connected to private network

# من PowerShell
$natConfig = Get-NetNatStaticMapping
Add-NetNat -Name "InternetNAT" -InternalIPInterfaceAddressPrefix "192.168.1.0/24"

تمرين 3: اختبار الـ Routing

# من جهاز على LAN (192.168.1.x)
ping 172.16.1.1          # شبكة بعيدة
tracert 172.16.1.1       # تتبع المسار
route print              # عرض جدول الـ Routing
