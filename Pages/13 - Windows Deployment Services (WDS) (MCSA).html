WDS - Windows Deployment Services الجزء الأول

شرح نظري وتطبيق عملي لإدارة Windows Server.

العودة إلى فهرس الدروس

الـ WDS بيخليك تثبّت Windows على أجهزة كتير عبر الشبكة من غير ما تحتاج USB أو DVD لكل جهاز. مثالى للشركات اللى محتاجة تثبّت نظام على عشرات أو مئات الأجهزة.

مكونات WDS

  • WDS Server: السيرفر اللى بيحتضن الـ Images
  • Boot Image (WinPE): البيئة اللى بتشتغل أول ما الجهاز يبدأ عبر الشبكة
  • Install Image: الـ Windows Image اللى هيتثبّت
  • PXE Boot: بروتوكول تشغيل الجهاز عبر الشبكة
  • DHCP: مطلوب لتوزيع الـ IPs على الأجهزة الجديدة

متطلبات WDS

  • Active Directory Domain
  • DHCP Server
  • DNS Server
  • NTFS Partition لتخزين الـ Images
  • شبكة بـ PXE Support

تثبيت وإعداد WDS

# تثبيت الـ Role
Install-WindowsFeature -Name WDS -IncludeManagementTools

# إعداد WDS
WDSUtil /Initialize-Server /RemInst:"D:\RemoteInstall"
WDSUtil /Set-Server /AnswerClients:All

# أو من PowerShell
Import-Module WDS
Initialize-WdsServer -RemInstPath "D:\RemoteInstall" -Authorize

إضافة Boot Image

# استخراج Boot Image من الـ ISO
# Mount الـ ISO أولاً
Mount-DiskImage -ImagePath "C:\Windows2016.iso"

# نسخ الـ boot.wim
Copy-Item "E:\sources\boot.wim" "C:\Temp\"

# إضافة لـ WDS
Import-WdsBootImage -Path "C:\Temp\boot.wim" -NewImageName "Windows PE Boot" -NewDescription "Boot Environment for Deployment"

إضافة Install Image

# إنشاء Image Group
New-WdsImageGroup -Name "Windows Server 2016"

# إضافة Install Image
Import-WdsInstallImage -Path "E:\sources\install.wim" -ImageGroup "Windows Server 2016" -ImageName "Windows Server 2016 Standard" -NewImageName "WS2016 Standard"

التطبيق العملى - WDS الجزء الأول

تمرين 1: إعداد WDS Server كامل

# تثبيت الـ Role
Install-WindowsFeature -Name WDS, WDS-Deployment, WDS-Transport -IncludeManagementTools

# إنشاء مجلد الـ RemoteInstall
New-Item -Path "D:\RemoteInstall" -ItemType Directory

# إعداد WDS
WDSUtil /Initialize-Server /RemInst:"D:\RemoteInstall"
WDSUtil /Set-Server /AnswerClients:All
WDSUtil /Set-Server /PxePromptPolicy /New:OptOut  # بيبدأ تلقائى بدون Prompt

تمرين 2: إضافة الـ Images

# Mount الـ ISO
Mount-DiskImage -ImagePath "C:\WS2016.iso"
$drive = (Get-DiskImage "C:\WS2016.iso" | Get-Volume).DriveLetter

# إضافة Boot Image
Import-WdsBootImage -Path "${drive}:\sources\boot.wim" -NewImageName "WinPE WDS Boot"

# إنشاء Image Group وإضافة Install Image
New-WdsImageGroup -Name "Windows Server 2016"
Import-WdsInstallImage -Path "${drive}:\sources\install.wim" -ImageGroup "Windows Server 2016" -ImageName "Windows Server 2016 SERVERSTANDARD" -NewImageName "WS2016 Standard Desktop"

# Unmount الـ ISO
Dismount-DiskImage -ImagePath "C:\WS2016.iso"

تمرين 3: اختبار PXE Boot

  1. اعمل VM جديد بدون HDD أو بـ HDD فاضى
  2. فى الـ Boot Options: فعّل Network Boot / PXE
  3. شغّل الـ VM - المفروض يبدأ الـ WDS Boot
  4. اتبع خطوات التثبيت
