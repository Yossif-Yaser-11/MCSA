User Accounts فى Active Directory

شرح نظري وتطبيق عملي لإدارة Windows Server.

العودة إلى فهرس الدروس

إدارة حسابات المستخدمين هى من أهم مهام الـ AD Administrator. كل مستخدم فى الشبكة محتاج Account عشان يقدر يدخل على الـ Domain.

خصائص User Account

  • Username (SAM Account Name): الاسم المستخدم للدخول - لازم فريد فى الـ Domain
  • UPN (User Principal Name): ahmed@networkat.local - الصيغة الحديثة
  • Display Name: الاسم الكامل كما يظهر
  • Password: لازم يتبع الـ Password Policy
  • Account Status: Enabled / Disabled
  • Logon Hours: تحديد مواعيد الدخول
  • Logon Workstations: تحديد الأجهزة المسموح بالدخول منها

إنشاء User من PowerShell

New-ADUser `
    -Name "Ahmed Mohamed" `
    -SamAccountName "ahmed.mohamed" `
    -UserPrincipalName "ahmed.mohamed@networkat.local" `
    -GivenName "Ahmed" `
    -Surname "Mohamed" `
    -Department "IT" `
    -Title "Network Engineer" `
    -EmailAddress "ahmed@networkat.local" `
    -Path "OU=Users,OU=IT_Department,DC=networkat,DC=local" `
    -AccountPassword (ConvertTo-SecureString "P@ssw0rd123" -AsPlainText -Force) `
    -Enabled $true `
    -ChangePasswordAtLogon $true

عمليات User Account

# تعطيل حساب
Disable-ADAccount -Identity "ahmed.mohamed"

# تفعيل حساب
Enable-ADAccount -Identity "ahmed.mohamed"

# تغيير كلمة السر
Set-ADAccountPassword -Identity "ahmed.mohamed" -Reset -NewPassword (ConvertTo-SecureString "NewP@ss123" -AsPlainText -Force)

# إلغاء قفل الحساب
Unlock-ADAccount -Identity "ahmed.mohamed"

# حذف حساب
Remove-ADUser -Identity "ahmed.mohamed" -Confirm:$false

# نقل لـ OU تانية
Move-ADObject -Identity "CN=Ahmed Mohamed,OU=IT,DC=networkat,DC=local" -TargetPath "OU=HR,DC=networkat,DC=local"

Password Policy

الـ Default Domain Password Policy بتنطبق على كل المستخدمين:

الإعداد القيمة الافتراضية
Minimum Length 7 حروف
Complexity مفعّل (أحرف كبيرة + صغيرة + أرقام + رموز)
Maximum Age 42 يوم
Minimum Age 1 يوم
History 24 كلمة سر قديمة
Lockout Threshold 0 (مش مفعّل افتراضياً)

التطبيق العملى - User Accounts

تمرين 1: إنشاء مجموعة Users

# إنشاء 5 Users بـ Loop
$users = @(
    @{Name="Ahmed Ali"; Sam="ahmed.ali"; Dept="IT"},
    @{Name="Sara Omar"; Sam="sara.omar"; Dept="HR"},
    @{Name="Mohamed Khaled"; Sam="mohamed.khaled"; Dept="Finance"},
    @{Name="Fatima Hassan"; Sam="fatima.hassan"; Dept="IT"},
    @{Name="Omar Ibrahim"; Sam="omar.ibrahim"; Dept="HR"}
)

foreach ($user in $users) {
    New-ADUser `
        -Name $user.Name `
        -SamAccountName $user.Sam `
        -UserPrincipalName "$($user.Sam)@networkat.local" `
        -Department $user.Dept `
        -Path "OU=Users,OU=$($user.Dept)_Department,DC=networkat,DC=local" `
        -AccountPassword (ConvertTo-SecureString "Welcome@123" -AsPlainText -Force) `
        -Enabled $true `
        -ChangePasswordAtLogon $true
    Write-Host "Created: $($user.Name)"
}

تمرين 2: Password Policy

# تعديل الـ Default Domain Password Policy
Set-ADDefaultDomainPasswordPolicy -Identity "networkat.local" `
    -MinPasswordLength 10 `
    -PasswordHistoryCount 5 `
    -MaxPasswordAge (New-TimeSpan -Days 90) `
    -LockoutThreshold 5 `
    -LockoutDuration (New-TimeSpan -Minutes 30) `
    -LockoutObservationWindow (New-TimeSpan -Minutes 30)

# التحقق
Get-ADDefaultDomainPasswordPolicy

تمرين 3: البحث عن Users

# Users غير نشطين منذ 30 يوم
$date = (Get-Date).AddDays(-30)
Get-ADUser -Filter {LastLogonDate -lt $date -and Enabled -eq $true} -Properties LastLogonDate

# Users بدون كلمة سر منتهية
Get-ADUser -Filter {PasswordNeverExpires -eq $true} -Properties PasswordNeverExpires
