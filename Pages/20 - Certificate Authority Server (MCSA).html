Certificate Authority Server

شرح نظري وتطبيق عملي لإدارة Windows Server.

العودة إلى فهرس الدروس

الـ Certificate Authority (CA) هو الجهة الموثوقة اللى بتصدر الشهادات الرقمية. الشهادات بتستخدم لتشفير الاتصالات والتحقق من الهوية.

استخدامات الشهادات الرقمية

  • HTTPS: تشفير مواقع الويب
  • Email Encryption: تشفير البريد الإلكترونى (S/MIME)
  • VPN: المصادقة فى اتصالات VPN
  • Smart Card: تسجيل الدخول بالبطاقة الذكية
  • Code Signing: التحقق من مصدر البرامج
  • Network Authentication: 802.1X للـ Wi-Fi والشبكات السلكية

أنواع الـ CA

النوعالوصف
Enterprise Root CAأعلى مستوى - مثبّت على Domain - للشركات
Enterprise Subordinate CAتحت الـ Root CA - يصدر الشهادات للمستخدمين
Standalone Root CAمستقل عن الـ Domain - للـ Labs
Standalone Subordinate CAتحت الـ Root ولكن مستقل

التثبيت والإعداد

# تثبيت AD CS
Install-WindowsFeature -Name AD-Certificate -IncludeManagementTools

# إعداد Enterprise Root CA
Install-AdcsCertificationAuthority `
    -CAType EnterpriseRootCa `
    -CACommonName "Networkat-Root-CA" `
    -KeyLength 4096 `
    -HashAlgorithmName SHA256 `
    -ValidityPeriod Years `
    -ValidityPeriodUnits 10 `
    -Force

إصدار الشهادات

# إنشاء Certificate Template (من الـ GUI)
# certsrv.msc → Certificate Templates → Manage
# Duplicate Template → تعديل الإعدادات → Publish

# طلب شهادة يدوياً
# certmgr.msc → Personal → Certificates → Request New Certificate

# Autoenrollment (تلقائى)
# GPO → Computer Config → Security Settings → Public Key Policies → Certificate Services Client
# Enrollment Policy: Enabled
# Automatic Certificate Management: Enabled

إدارة الشهادات

# عرض الشهادات
Get-ChildItem Cert:\LocalMachine\My
Get-ChildItem Cert:\CurrentUser\My

# إصدار شهادة للـ Web Server
$cert = New-SelfSignedCertificate -DnsName "www.networkat.local" -CertStoreLocation Cert:\LocalMachine\My

# إلغاء شهادة
Revoke-CACertificate -SerialNumber "1234567890" -Reason CessationOfOperation

التطبيق العملى - Certificate Authority

تمرين 1: تثبيت CA كامل

# تثبيت الـ Role
Install-WindowsFeature -Name AD-Certificate, ADCS-Web-Enrollment -IncludeManagementTools

# إعداد Enterprise Root CA
Install-AdcsCertificationAuthority `
    -CAType EnterpriseRootCa `
    -CACommonName "Networkat-Root-CA" `
    -CADistinguishedNameSuffix "DC=networkat,DC=local" `
    -KeyLength 4096 `
    -HashAlgorithmName SHA256 `
    -ValidityPeriod Years `
    -ValidityPeriodUnits 10 `
    -Force

# إعداد Web Enrollment
Install-AdcsWebEnrollment -Force

# التحقق
Get-CACertificate
certutil -ping

تمرين 2: إصدار شهادة للـ Web Server

# طلب شهادة للـ IIS
$cert = Get-Certificate -Template WebServer -SubjectName "CN=www.networkat.local" -CertStoreLocation Cert:\LocalMachine\My

# ربط الشهادة بـ IIS
Import-Module WebAdministration
New-WebBinding -Name "Default Web Site" -Protocol https -Port 443
$binding = Get-WebBinding -Name "Default Web Site" -Protocol https
$binding.AddSslCertificate($cert.Certificate.Thumbprint, "My")

# التحقق
Get-WebBinding -Name "Default Web Site"

تمرين 3: Certificate Autoenrollment عبر GPO

# من Group Policy Management
# Computer Config → Windows Settings → Security Settings → Public Key Policies
# Certificate Services Client - Auto-Enrollment Settings
# Configuration Model: Enabled
# Renew expired certificates: Checked
# Update certificates: Checked

# التحقق
gpupdate /force
certutil -pulse
