Active Directory - قاعدة بيانات الشبكة

شرح نظري وتطبيق عملي لإدارة Windows Server.

العودة إلى فهرس الدروس

الـ Active Directory (AD) هو خدمة الدليل من Microsoft. بيخزّن معلومات عن كل حاجة فى الشبكة: المستخدمين، الأجهزة، المجموعات، السياسات، وبيوفّر خدمات المصادقة والتفويض.

مكونات الـ Active Directory

  • Objects: أى عنصر فى الـ AD (مستخدم، جهاز، مجموعة، Printer)
  • OU (Organizational Unit): مجلد لتنظيم الـ Objects
  • Domain: حدود الإدارة الأساسية
  • Tree: مجموعة Domains بنفس الـ Namespace
  • Forest: أعلى مستوى - بيضم كل الـ Trees

Active Directory Structure

Forest: company.com
├── Tree: company.com
│   ├── Domain: company.com (Root Domain)
│   │   ├── OU: Users
│   │   │   ├── User: Ahmed
│   │   │   └── User: Sara
│   │   ├── OU: Computers
│   │   │   ├── Computer: PC-001
│   │   │   └── Computer: SRV-01
│   │   └── OU: Groups
│   └── Child Domain: cairo.company.com
└── Tree: subsidiary.com

AD DS Services

الخدمة الاختصار الوظيفة
Active Directory Domain Services AD DS الخدمة الرئيسية - إدارة الـ Domain
Active Directory Certificate Services AD CS إصدار الشهادات الرقمية
Active Directory Federation Services AD FS Single Sign-On بين Organizations
Active Directory Lightweight Directory AD LDS Directory بدون Domain
Active Directory Rights Management AD RMS حماية المستندات

مصادقة الـ Active Directory

الـ AD بيستخدم بروتوكول Kerberos للمصادقة:

  1. المستخدم بيدخل Username و Password
  2. الـ DC بيتحقق ويدّى الـ TGT (Ticket Granting Ticket)
  3. المستخدم بيستخدم الـ TGT عشان يطلب Service Tickets
  4. السيرفرات بتقبل الـ Service Ticket بدون ما تتصل بالـ DC

أوامر AD PowerShell المهمة

# البحث فى الـ AD
Get-ADUser -Filter * | Select Name, SamAccountName
Get-ADComputer -Filter * | Select Name
Get-ADGroup -Filter * | Select Name

# معلومات تفصيلية
Get-ADUser -Identity "ahmed" -Properties *

# البحث بشرط
Get-ADUser -Filter {Department -eq "IT"}

التطبيق العملى - Active Directory

تمرين 1: إنشاء Structure منظم

# إنشاء OUs
New-ADOrganizationalUnit -Name "IT_Department" -Path "DC=networkat,DC=local"
New-ADOrganizationalUnit -Name "HR_Department" -Path "DC=networkat,DC=local"
New-ADOrganizationalUnit -Name "Servers" -Path "DC=networkat,DC=local"

# إنشاء Sub-OUs
New-ADOrganizationalUnit -Name "Users" -Path "OU=IT_Department,DC=networkat,DC=local"
New-ADOrganizationalUnit -Name "Computers" -Path "OU=IT_Department,DC=networkat,DC=local"

تمرين 2: استعراض الـ AD

# عرض كل الـ OUs
Get-ADOrganizationalUnit -Filter * | Select Name, DistinguishedName

# عرض Objects فى OU معين
Get-ADObject -Filter * -SearchBase "OU=IT_Department,DC=networkat,DC=local"

# عرض معلومات الـ Domain
Get-ADDomain | Select DNSRoot, NetBIOSName, DomainMode, PDCEmulator

تمرين 3: AD Users and Computers (GUI)

  1. افتح Active Directory Users and Computers
  2. استعرض هيكل الـ Domain
  3. اعمل OU جديدة باسم "Networkat_Staff"
  4. جوّالها اعمل Users و Computers Sub-OUs
  5. جرب تسحب User من مكان لتانى
