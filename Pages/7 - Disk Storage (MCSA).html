Disk Storage فى Windows Server

شرح نظري وتطبيق عملي لإدارة Windows Server.

العودة إلى فهرس الدروس

إدارة الأقراص الصلبة من أهم مهام الـ Windows Server Administrator. لازم تفهم الفرق بين أنواع الأقراص وطرق تقسيمها وإدارتها.

أنواع الأقراص

النوع الوصف الحد الأقصى
Basic Disk الافتراضى - بيستخدم Partitions عادية 4 Primary Partitions
Dynamic Disk متقدم - بيدعم Volumes معقدة غير محدود
GPT (GUID Partition Table) الحديث - بيدعم أقراص أكبر من 2TB 128 Partition
MBR (Master Boot Record) القديم - محدود 4 Primary / 2TB

أنواع Dynamic Volumes

النوع الأقراص الأداء الحماية
Simple Volume 1 عادى لا يوجد
Spanned Volume 2-32 عادى لا يوجد
Striped (RAID-0) 2-32 ممتاز لا يوجد
Mirrored (RAID-1) 2 قراءة أسرع نعم (نسخة كاملة)
RAID-5 3-32 جيد نعم (Parity)

Storage Spaces

الـ Storage Spaces ميزة حديثة بتخليك تجمّع أقراص فيزيائية فى Pool واحد وتعمل منه Spaces (Virtual Disks) بخصائص مختلفة.

# PowerShell - إنشاء Storage Pool
$disks = Get-PhysicalDisk -CanPool $true
New-StoragePool -FriendlyName "DataPool" -StorageSubsystemFriendlyName "Windows Storage*" -PhysicalDisks $disks

# إنشاء Virtual Disk بـ RAID-5
New-VirtualDisk -StoragePoolFriendlyName "DataPool" -FriendlyName "DataDisk" -Size 500GB -ResiliencySettingName "Parity"

# تهيئة وإضافة Drive Letter
Initialize-Disk -FriendlyName "DataDisk"
New-Partition -DiskNumber 2 -UseMaximumSize -DriveLetter E
Format-Volume -DriveLetter E -FileSystem NTFS -NewFileSystemLabel "Data"

أوامر إدارة الأقراص

# عرض الأقراص
Get-Disk
Get-Partition
Get-Volume

# تهيئة قرص جديد
Initialize-Disk -Number 1 -PartitionStyle GPT

# إنشاء Partition
New-Partition -DiskNumber 1 -UseMaximumSize -DriveLetter D
Format-Volume -DriveLetter D -FileSystem NTFS -NewFileSystemLabel "Data" -Confirm:$false

التطبيق العملى - Disk Storage

تمرين 1: إضافة قرص جديد

  1. فى الـ VM أضف قرص جديد 50 GB
  2. افتح Disk Management (diskmgmt.msc)
  3. الـ Disk الجديد هيظهر كـ Unknown/Not Initialized
  4. كليك يمين ← Initialize Disk ← اختار GPT
  5. كليك يمين على المساحة الفاضية ← New Simple Volume
  6. دّيه Drive Letter (مثلاً D:)
  7. هيّئه بـ NTFS

تمرين 2: PowerShell Disk Management

# عرض الأقراص
Get-Disk | Select Number, FriendlyName, Size, PartitionStyle, OperationalStatus

# تهيئة قرص رقم 1
Initialize-Disk -Number 1 -PartitionStyle GPT
New-Partition -DiskNumber 1 -UseMaximumSize -DriveLetter E
Format-Volume -DriveLetter E -FileSystem NTFS -NewFileSystemLabel "Data" -Confirm:$false

# التحقق
Get-Volume -DriveLetter E

تمرين 3: RAID-1 Mirror

# تحويل لـ Dynamic Disk أولاً
Set-Disk -Number 1 -IsOffline $false
Set-Disk -Number 2 -IsOffline $false

# إنشاء Mirror (من Disk Management GUI)
# 1. كليك يمين على الـ Volume ← Add Mirror
# 2. اختار الـ Disk التانى
# 3. Resync هيبدأ تلقائياً
