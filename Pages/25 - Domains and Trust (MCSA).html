Domains و Trust Relationships

شرح نظري وتطبيق عملي لإدارة Windows Server.

العودة إلى فهرس الدروس

فى الشركات الكبيرة، ممكن يكون فيه أكتر من Domain. الـ Trust Relationships بتخلى المستخدمين فى Domain يوصلوا لـ Resources فى Domain تانى.

أنواع الـ Trust

النوعالاتجاهالوصف
Parent-Child TrustTwo-way Transitiveبيتنشئ تلقائياً لما تضيف Child Domain
Tree-Root TrustTwo-way Transitiveبين الـ Root Domains فى نفس الـ Forest
Shortcut TrustOne أو Two-way Transitiveبتسرّع المصادقة بين Domains بعيدة
External TrustOne أو Two-way Non-transitiveمع Domain خارج الـ Forest
Forest TrustOne أو Two-way Transitiveبين Forest مختلفة - يعطى وصول لكل الـ Domains
Realm TrustOne أو Two-wayمع Kerberos Realm غير Microsoft (Linux)

Transitive vs Non-Transitive

  • Transitive: لو A يثق فى B، وـ B يثق فى C، فـ A يثق فى C تلقائياً
  • Non-Transitive: الثقة محصورة بين الـ Domains المحددة بس

إنشاء Trust

# إنشاء External Trust (One-way)
Netdom trust networkat.local /domain:partner.com /add /twoway

# من PowerShell
Add-ADTrustAccount -TargetDomainName "partner.com" -TrustDirection Bidirectional -TrustType External

# التحقق
Get-ADTrust -Filter *

Selective Authentication

بدل ما يديك وصول لكل الـ Resources فى الـ Forest التانية، بتحدد بالظبط أنهى Users من الـ Domain التانى يقدروا يوصلوا لأنهى Resources:

# تفعيل Selective Authentication على الـ Trust
Set-ADTrust -Identity "partner.com" -SelectiveAuth $true

# السماح لـ User بالوصول لـ Resource معين
$user = Get-ADUser -Identity "ahmed" -Server "partner.com"
$acl = Get-Acl "\\SRV-File\SharedData"
$rule = New-Object System.Security.AccessControl.FileSystemAccessRule($user, "Read", "Allow")
$acl.AddAccessRule($rule)
Set-Acl "\\SRV-File\SharedData" $acl

التطبيق العملى - Domains و Trusts

تمرين 1: إنشاء Child Domain

# على سيرفر جديد عايز يبقى DC لـ cairo.networkat.local
Install-WindowsFeature -Name AD-Domain-Services -IncludeManagementTools

Install-ADDSDomain `
    -NewDomainName "cairo" `
    -ParentDomainName "networkat.local" `
    -NewDomainNetbiosName "CAIRO" `
    -InstallDns:$true `
    -SafeModeAdministratorPassword (ConvertTo-SecureString "DSRM@Pass123" -AsPlainText -Force) `
    -Credential (Get-Credential "NETWORKAT\Administrator") `
    -Force:$true

# بعد الـ Restart، التحقق من الـ Trust
Get-ADTrust -Filter * -Server "networkat.local"

تمرين 2: إنشاء External Trust

# بين networkat.local وـ partner.com
# على SRV-DC01 فى networkat.local:
Netdom trust networkat.local /domain:partner.com /add /twoway /usero:Administrator /passwordo:PartnerPass123

# التحقق
Netdom query trust

# التحقق من PowerShell
Get-ADTrust -Filter * | Select Name, Direction, TrustType, IsTransitive

تمرين 3: الوصول عبر Trust

# من جهاز فى networkat.local
# الوصول لـ Resource فى partner.com
net use Z: \\SRV-Partner\SharedData /user:partner.com\ahmed PartnerPass

# أو فى الـ AD Users and Computers
# بتقدر تضيف User من partner.com لـ Group فى networkat.local
Add-ADGroupMember -Identity "DL_Shared_Read" -Members "partner.com\ahmed"
