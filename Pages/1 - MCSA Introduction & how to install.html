مقدمة MCSA 2016 وتثبيت Windows Server

شرح نظري وتطبيق عملي لإدارة Windows Server.

العودة إلى فهرس الدروس

الـ MCSA (Microsoft Certified Solutions Associate) شهادة من Microsoft بتثبت كفاءتك فى إدارة Windows Server. Windows Server 2016 هو نظام التشغيل المخصص للسيرفرات من Microsoft.

إصدارات Windows Server 2016

الإصدار الاستخدام الـ GUI
Datacenter بيئات الـ Virtualization الكثيفة نعم
Standard الشركات المتوسطة نعم
Essentials الشركات الصغيرة (حد 25 مستخدم) نعم
Core أى إصدار بدون GUI - للـ Admins المتقدمين لأ

متطلبات التثبيت

المكوّن الحد الأدنى الموصى به
المعالج 1.4 GHz 64-bit 2 GHz+
الـ RAM 512 MB (Core) / 2 GB (GUI) 16 GB+
القرص الصلب 32 GB 100 GB+
الشبكة Ethernet 1 Gbps 10 Gbps

طرق التثبيت

  • Clean Install: تثبيت جديد على قرص فاضى - الأفضل للأداء
  • Upgrade: ترقية من إصدار أقدم - محتاج تأكد من التوافق
  • Server Core: بدون واجهة رسومية - أسرع وأأمن وأقل استهلاكاً للـ Resources

Server Roles المهمة

  • Active Directory Domain Services (AD DS): إدارة المستخدمين والأجهزة
  • DNS Server: ترجمة الأسماء لعناوين IP
  • DHCP Server: توزيع العناوين تلقائياً
  • File and Storage Services: مشاركة الملفات
  • Web Server (IIS): استضافة المواقع
  • Hyper-V: الـ Virtualization

إضافة Role على Windows Server

! من الـ GUI
1. افتح Server Manager
2. دوس Add Roles and Features
3. اختار Role-based installation
4. اختار الـ Role المطلوب
5. دوس Install

! من PowerShell
Install-WindowsFeature -Name AD-Domain-Services -IncludeManagementTools
Install-WindowsFeature -Name DHCP -IncludeManagementTools
Install-WindowsFeature -Name DNS -IncludeManagementTools

التطبيق العملى - تثبيت Windows Server 2016

خطوات التثبيت

  1. حمّل ISO من موقع Microsoft Evaluation Center
  2. افتح VMware أو Hyper-V
  3. اعمل VM جديد: 2 CPU, 4 GB RAM, 60 GB HDD
  4. اختار الـ ISO وابدأ التثبيت
  5. اختار "Windows Server 2016 Standard (Desktop Experience)"
  6. اختار Custom Install
  7. اختار القرص وابدأ التثبيت
  8. حط كلمة سر للـ Administrator (لازم تكون قوية)

إعداد ما بعد التثبيت

# فى PowerShell
# تغيير اسم السيرفر
Rename-Computer -NewName "SRV-DC01" -Restart

# تعيين IP ثابت
New-NetIPAddress -InterfaceAlias "Ethernet" -IPAddress 192.168.1.10 -PrefixLength 24 -DefaultGateway 192.168.1.1
Set-DnsClientServerAddress -InterfaceAlias "Ethernet" -ServerAddresses 192.168.1.10

# تفعيل Remote Desktop
Set-ItemProperty -Path "HKLM:\System\CurrentControlSet\Control\Terminal Server" -Name "fDenyTSConnections" -Value 0
Enable-NetFirewallRule -DisplayGroup "Remote Desktop"

# تثبيت AD DS
Install-WindowsFeature -Name AD-Domain-Services -IncludeManagementTools

التحقق من الإعداد

# التحقق من الـ IP
ipconfig /all

# التحقق من الـ Features المثبتة
Get-WindowsFeature | Where-Object {$_.Installed -eq $true}
