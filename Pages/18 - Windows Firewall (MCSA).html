Windows Firewall

شرح نظري وتطبيق عملي لإدارة Windows Server.

العودة إلى فهرس الدروس

الـ Windows Firewall بيحمى السيرفر من الاتصالات غير المصرح بها. بيتحكم فى الـ Traffic الداخل والخارج بناءً على Rules محددة.

Windows Firewall Profiles

  • Domain Profile: بيطبق لما الجهاز متصل بالـ Domain
  • Private Profile: للشبكات الخاصة الموثوقة
  • Public Profile: للشبكات العامة - الأشد تقييداً

إدارة الـ Firewall

# عرض حالة الـ Firewall
Get-NetFirewallProfile | Select Name, Enabled, DefaultInboundAction, DefaultOutboundAction

# تفعيل/تعطيل الـ Firewall
Set-NetFirewallProfile -Profile Domain -Enabled True
Set-NetFirewallProfile -All -Enabled True

# تغيير السلوك الافتراضى
Set-NetFirewallProfile -Profile Domain -DefaultInboundAction Block -DefaultOutboundAction Allow

إنشاء Firewall Rules

# السماح بـ Port محدد (HTTP)
New-NetFirewallRule -DisplayName "Allow HTTP" -Direction Inbound -Protocol TCP -LocalPort 80 -Action Allow -Profile Domain

# السماح بـ Port Range
New-NetFirewallRule -DisplayName "Allow RDP Range" -Direction Inbound -Protocol TCP -LocalPort 3389 -Action Allow -RemoteAddress "192.168.1.0/24"

# منع تطبيق معين
New-NetFirewallRule -DisplayName "Block BitTorrent" -Direction Outbound -Program "C:\Program Files\BitTorrent\BitTorrent.exe" -Action Block

# السماح بـ ICMP (Ping)
New-NetFirewallRule -DisplayName "Allow Ping" -Direction Inbound -Protocol ICMPv4 -IcmpType 8 -Action Allow

إدارة Rules الموجودة

# عرض كل الـ Rules
Get-NetFirewallRule | Where-Object Enabled -eq True | Select DisplayName, Direction, Action

# تعطيل Rule
Disable-NetFirewallRule -DisplayName "Allow HTTP"

# حذف Rule
Remove-NetFirewallRule -DisplayName "Allow HTTP"

# نسخ Rule لـ GPO
# Computer Config → Windows Settings → Security Settings → Windows Firewall with Advanced Security

التطبيق العملى - Windows Firewall

تمرين 1: إعداد Firewall للـ Web Server

# السيرفر ده Web Server - نسمح HTTP و HTTPS بس من الإنترنت

# Block كل حاجة Inbound بالـ Default
Set-NetFirewallProfile -Profile Public -DefaultInboundAction Block

# السماح بـ HTTP و HTTPS
New-NetFirewallRule -DisplayName "Web HTTP" -Direction Inbound -Protocol TCP -LocalPort 80 -Action Allow -Profile Public
New-NetFirewallRule -DisplayName "Web HTTPS" -Direction Inbound -Protocol TCP -LocalPort 443 -Action Allow -Profile Public

# السماح بـ RDP من الـ LAN بس
New-NetFirewallRule -DisplayName "RDP from LAN" -Direction Inbound -Protocol TCP -LocalPort 3389 -RemoteAddress "192.168.1.0/24" -Action Allow

# السماح بـ Ping للـ Monitoring
New-NetFirewallRule -DisplayName "Allow Ping" -Direction Inbound -Protocol ICMPv4 -IcmpType 8 -RemoteAddress "192.168.1.0/24" -Action Allow

تمرين 2: Firewall via Group Policy

# من GPMC:
# Computer Config → Security Settings → Windows Firewall with Advanced Security
# Inbound Rules → New Rule
# Port → TCP → 443 → Allow → Domain,Private

# أو بـ PowerShell على الـ GPO
Set-GPRegistryValue -Name "Firewall_Policy" -Key "HKLM\SOFTWARE\Policies\Microsoft\WindowsFirewall\DomainProfile" -ValueName "EnableFirewall" -Type DWORD -Value 1

تمرين 3: Firewall Logging

# تفعيل الـ Logging
Set-NetFirewallProfile -Profile Domain -LogFileName "C:\Windows\System32\LogFiles\Firewall\pfirewall.log" -LogMaxSizeKilobytes 4096 -LogAllowed True -LogBlocked True

# قراءة الـ Log
Get-Content "C:\Windows\System32\LogFiles\Firewall\pfirewall.log" | Select-Object -Last 50
