Promoting Server - ترقية السيرفر لـ Domain Controller

شرح نظري وتطبيق عملي لإدارة Windows Server.

العودة إلى فهرس الدروس

الـ Domain Controller (DC) هو السيرفر اللى بيتحكم فى الـ Active Directory Domain. بيحفظ قاعدة بيانات المستخدمين والأجهزة ومسؤول عن المصادقة.

مصطلحات أساسية

المصطلح الشرح
Domain مجموعة من الأجهزة والمستخدمين تحت إدارة مركزية
Domain Controller (DC) السيرفر المسؤول عن الـ Domain
Forest مجموعة من الـ Domains بتشارك Schema واحدة
Tree مجموعة Domains بنفس الـ Namespace
Schema تعريف أنواع الـ Objects فى الـ AD
FSMO Roles وظائف خاصة موزعة على الـ DCs

خطوات الـ Promotion

  1. تثبيت AD DS Role أولاً
  2. تشغيل Promote this server to a domain controller
  3. اختيار: Add a new forest (للـ Domain الأول)
  4. كتابة اسم الـ Domain: networkat.local
  5. تحديد الـ Forest Functional Level و Domain Functional Level
  6. تعيين كلمة سر الـ DSRM (Directory Services Restore Mode)
  7. مراجعة الإعدادات والتثبيت
  8. السيرفر هيعمل Restart تلقائياً

FSMO Roles - الخمس وظائف

الوظيفة النطاق الوظيفة
Schema Master Forest التحكم فى الـ Schema
Domain Naming Master Forest إضافة وحذف الـ Domains
PDC Emulator Domain مزامنة الوقت وتغيير كلمات السر
RID Master Domain توزيع الـ RIDs على الـ DCs
Infrastructure Master Domain مزامنة الـ Objects بين الـ Domains

إضافة DC ثانى (Redundancy)

# على السيرفر الجديد
Install-WindowsFeature -Name AD-Domain-Services -IncludeManagementTools
Import-Module ADDSDeployment
Install-ADDSDomainController -DomainName "networkat.local" -InstallDns:$true -Credential (Get-Credential)

التطبيق العملى - Promotion

تمرين 1: Promote من PowerShell

# تثبيت الـ Role
Install-WindowsFeature -Name AD-Domain-Services -IncludeManagementTools

# Promote للـ Domain الأول
Import-Module ADDSDeployment
Install-ADDSForest `
    -DomainName "networkat.local" `
    -DomainNetbiosName "NETWORKAT" `
    -ForestMode "WinThreshold" `
    -DomainMode "WinThreshold" `
    -InstallDns:$true `
    -SafeModeAdministratorPassword (ConvertTo-SecureString "DSRM@Pass123" -AsPlainText -Force) `
    -Force:$true

تمرين 2: التحقق بعد الـ Promotion

# التحقق من الـ Domain
Get-ADDomain

# التحقق من الـ DC
Get-ADDomainController

# التحقق من الـ FSMO
netdom query fsmo

# التحقق من الـ DNS
Get-DnsServerZone
nslookup networkat.local

تمرين 3: انضمام جهاز للـ Domain

# من PowerShell على الـ Client
Add-Computer -DomainName "networkat.local" -Credential (Get-Credential) -Restart

# التحقق
(Get-WmiObject Win32_ComputerSystem).Domain
