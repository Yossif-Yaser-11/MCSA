DFS و FSRM

شرح نظري وتطبيق عملي لإدارة Windows Server.

العودة إلى فهرس الدروس

DFS - Distributed File System

الـ DFS بيخليك تنظّم الـ Shared Folders من سيرفرات مختلفة تحت Namespace واحدة موحدة. المستخدمين بيشوفوا مسار واحد بسيط بدل ما يتذكروا اسم كل سيرفر.

مكونات DFS

  • DFS Namespace: الشجرة الافتراضية (مثلاً \networkat.local\Data)
  • DFS Replication: مزامنة الملفات بين السيرفرات تلقائياً
  • DFS Folder Targets: المسارات الفعلية للـ Shared Folders
# تثبيت DFS
Install-WindowsFeature -Name FS-DFS-Namespace, FS-DFS-Replication -IncludeManagementTools

# إنشاء DFS Namespace
New-DfsnRoot -Path "\\networkat.local\Data" -TargetPath "\\SRV-File01\Data" -Type DomainV2

# إضافة مجلدات
New-DfsnFolder -Path "\\networkat.local\Data\HR" -TargetPath "\\SRV-File01\HR$"
New-DfsnFolder -Path "\\networkat.local\Data\IT" -TargetPath "\\SRV-File01\IT$"

# إضافة Target ثانى للـ Redundancy
New-DfsnFolderTarget -Path "\\networkat.local\Data\HR" -TargetPath "\\SRV-File02\HR$"

DFS Replication

# إنشاء Replication Group
New-DfsReplicationGroup -GroupName "HR_Replication"
Add-DfsrMember -GroupName "HR_Replication" -ComputerName "SRV-File01","SRV-File02"
New-DfsReplicatedFolder -GroupName "HR_Replication" -FolderName "HR_Data"
Add-DfsrConnection -GroupName "HR_Replication" -SourceComputerName "SRV-File01" -DestinationComputerName "SRV-File02"

FSRM - File Server Resource Manager

الـ FSRM بيوفّر أدوات متقدمة لإدارة الـ Storage:

  • Quota Management: تحديد حصص الـ Storage
  • File Screening: منع أنواع ملفات معينة
  • Storage Reports: تقارير تفصيلية عن الاستخدام
# تثبيت FSRM
Install-WindowsFeature -Name FS-Resource-Manager -IncludeManagementTools

# Storage Report
New-FsrmStorageReport -Name "Weekly_Report" `
    -Namespace "D:\Company" `
    -ReportType @("LargeFiles","QuotaUsage","FilesByOwner") `
    -Schedule (New-FsrmScheduledTask -Weekly -Day Sunday -Time "02:00")

التطبيق العملى - DFS

تمرين 1: DFS Namespace

# على SRV-DC01
Install-WindowsFeature -Name FS-DFS-Namespace, FS-DFS-Replication -IncludeManagementTools

# إنشاء الـ Namespace
New-DfsnRoot -Path "\\networkat.local\Company" -TargetPath "\\SRV-File01\Company" -Type DomainV2

# إضافة الأقسام
$shares = @("HR","IT","Finance","Shared","Management")
foreach ($share in $shares) {
    New-DfsnFolder -Path "\\networkat.local\Company\$share" -TargetPath "\\SRV-File01\$share`$"
    Write-Host "Added: $share"
}

# التحقق
Get-DfsnFolder -Path "\\networkat.local\Company\*"

تمرين 2: DFS Replication

# إعداد Replication بين سيرفرين
New-DfsReplicationGroup -GroupName "Company_Replication" -Description "Replicate Company Data"
Add-DfsrMember -GroupName "Company_Replication" -ComputerName "SRV-File01","SRV-File02"

$folders = @("HR","IT","Shared")
foreach ($folder in $folders) {
    New-DfsReplicatedFolder -GroupName "Company_Replication" -FolderName $folder
}

Add-DfsrConnection -GroupName "Company_Replication" `
    -SourceComputerName "SRV-File01" `
    -DestinationComputerName "SRV-File02" `
    -CreateOneWay $false

# التحقق من الـ Replication
Get-DfsrState -GroupName "Company_Replication"
