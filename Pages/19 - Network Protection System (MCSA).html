Network Protection System فى Windows Server

شرح نظري وتطبيق عملي لإدارة Windows Server.

العودة إلى فهرس الدروس

الحماية الكاملة للشبكة بتحتاج أكتر من Firewall. Windows Server بيوفّر مجموعة من الأدوات للحماية المتكاملة.

NAP - Network Access Protection

الـ NAP بيتحقق من صحة الجهاز قبل ما يسمحله يدخل الشبكة. لو الجهاز مش محدّث أو عليه فيروس، بيتحوّله لـ Quarantine Network.

  • Health Policies: بتحدد متطلبات صحة الجهاز (مثلاً Windows Update مفعّل، Antivirus محدّث)
  • Network Policies: بتحدد ماذا يحدث لو الجهاز مش سليم
  • Remediation: إصلاح تلقائى للمشاكل المكتشفة

Windows Defender

# التحقق من حالة Windows Defender
Get-MpComputerStatus

# تحديث التعريفات
Update-MpSignature

# فحص سريع
Start-MpScan -ScanType QuickScan

# فحص شامل
Start-MpScan -ScanType FullScan

# إضافة Exclusion
Add-MpPreference -ExclusionPath "D:\SQL_Data"

# عرض الـ Threats المكتشفة
Get-MpThreatDetection

Advanced Threat Protection

  • Microsoft Defender ATP: حماية متقدمة ضد التهديدات
  • Credential Guard: حماية بيانات الاعتماد
  • Device Guard: منع تشغيل الكود غير الموثوق
  • EMET (Enhanced Mitigation Experience Toolkit): حماية إضافية للتطبيقات

Security Auditing

# تفعيل الـ Audit Policies
AuditPol /set /category:"Logon/Logoff" /success:enable /failure:enable
AuditPol /set /category:"Account Management" /success:enable /failure:enable
AuditPol /set /category:"Object Access" /success:enable /failure:enable

# قراءة الـ Security Events
Get-WinEvent -LogName Security | Where-Object {$_.Id -eq 4625} | Select TimeCreated, Message | head -10
# Event 4625: Failed Logon
# Event 4624: Successful Logon
# Event 4720: User Account Created
# Event 4740: Account Locked Out

التطبيق العملى - Network Protection

تمرين 1: Windows Defender Management

# إعداد Windows Defender عبر PowerShell
Set-MpPreference -DisableRealtimeMonitoring $false
Set-MpPreference -SignatureUpdateInterval 4  # تحديث كل 4 ساعات
Set-MpPreference -SubmitSamplesConsent 2      # إرسال Samples تلقائياً
Set-MpPreference -MAPSReporting Advanced      # الانضمام لـ MAPS

# Scheduled Scan
Set-MpPreference -ScanScheduleDay 7          # كل أحد
Set-MpPreference -ScanScheduleTime 120        # الساعة 2 صباحاً

# التحقق من الإعدادات
Get-MpPreference | Select DisableRealtimeMonitoring, SignatureUpdateInterval, ScanScheduleDay

تمرين 2: Security Event Monitoring

# Script لمراقبة محاولات الاختراق
$failedLogons = Get-WinEvent -LogName Security -FilterHashtable @{Id=4625} | `
    Where-Object {$_.TimeCreated -gt (Get-Date).AddHours(-1)} | `
    Select TimeCreated, @{N="Account";E={$_.Properties[5].Value}}, @{N="SourceIP";E={$_.Properties[19].Value}}

$failedLogons | Group-Object SourceIP | Sort-Object Count -Descending | Select Count, Name

# لو IP معين بيحاول أكتر من 10 مرات
$suspiciousIPs = $failedLogons | Group-Object SourceIP | Where-Object {$_.Count -gt 10}
$suspiciousIPs | ForEach-Object {
    Write-Host "ALERT: Brute Force from $($_.Name) - $($_.Count) attempts" -ForegroundColor Red
    # ممكن تبلوكه تلقائياً بالـ Firewall
    New-NetFirewallRule -DisplayName "Block $($_.Name)" -Direction Inbound -RemoteAddress $_.Name -Action Block
}
