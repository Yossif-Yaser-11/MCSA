Share Folders و File Permissions

شرح نظري وتطبيق عملي لإدارة Windows Server.

العودة إلى فهرس الدروس

مشاركة الملفات وإدارة الصلاحيات من أهم مهام الـ File Server Administrator. لازم تفهم الفرق بين الـ Share Permissions والـ NTFS Permissions.

NTFS Permissions

بتطبّق على مستوى الـ File System - بتأثر على كل الوصول سواء محلى أو عبر الشبكة:

الصلاحيةالوصف
Full Controlكل الصلاحيات + تغيير الـ Permissions
Modifyقراءة + كتابة + حذف
Read & Executeقراءة وتشغيل البرامج
Readقراءة فقط
Writeكتابة فقط - مش بيقدر يقرأ
List Folder Contentsعرض محتويات المجلد فقط

Share Permissions

بتطبّق فقط على الوصول عبر الشبكة - 3 مستويات بس:

  • Full Control: كل الصلاحيات
  • Change: قراءة + كتابة + حذف
  • Read: قراءة فقط

القاعدة المهمة

لما المستخدم بيوصل عبر الشبكة، بيتطبق عليه الأضيق بين الـ NTFS Permissions والـ Share Permissions:

مثال:
- NTFS Permission: Full Control
- Share Permission: Read
= النتيجة: Read (الأضيق)

- NTFS Permission: Read
- Share Permission: Full Control
= النتيجة: Read (الأضيق)

إنشاء Shared Folder

# من PowerShell
New-Item -Path "D:\Shared\HR_Data" -ItemType Directory

# مشاركة المجلد
New-SmbShare -Name "HR_Data" -Path "D:\Shared\HR_Data" -Description "HR Department Data" -FullAccess "Administrators" -ChangeAccess "DL_HR_RW" -ReadAccess "DL_HR_Read"

# إعداد NTFS Permissions
$acl = Get-Acl "D:\Shared\HR_Data"
$rule = New-Object System.Security.AccessControl.FileSystemAccessRule("DL_HR_RW","Modify","ContainerInherit,ObjectInherit","None","Allow")
$acl.AddAccessRule($rule)
Set-Acl -Path "D:\Shared\HR_Data" -AclObject $acl

Inheritance

الـ NTFS Permissions بتنتقل من المجلد الأب للمجلدات الفرعية تلقائياً. ممكن تقطع الـ Inheritance عشان تدى صلاحيات مختلفة:

# قطع الـ Inheritance
$acl = Get-Acl "D:\Shared\HR_Data\Confidential"
$acl.SetAccessRuleProtection($true, $false)  # قطع الـ Inheritance وعدم نسخ الـ Rules
Set-Acl -Path "D:\Shared\HR_Data\Confidential" -AclObject $acl

التطبيق العملى - File Permissions

تمرين 1: إعداد File Server

# تثبيت File Server Role
Install-WindowsFeature -Name FS-FileServer -IncludeManagementTools

# إنشاء هيكل المجلدات
New-Item -Path "D:\Company" -ItemType Directory
New-Item -Path "D:\Company\HR" -ItemType Directory
New-Item -Path "D:\Company\IT" -ItemType Directory
New-Item -Path "D:\Company\Shared" -ItemType Directory
New-Item -Path "D:\Company\Management" -ItemType Directory

# مشاركة كل قسم
New-SmbShare -Name "HR$" -Path "D:\Company\HR" -FullAccess "Administrators" -ChangeAccess "GG_HR_Staff"
New-SmbShare -Name "IT$" -Path "D:\Company\IT" -FullAccess "Administrators" -ChangeAccess "GG_IT_Staff"
New-SmbShare -Name "Shared" -Path "D:\Company\Shared" -FullAccess "Administrators" -ReadAccess "Domain Users"

تمرين 2: إعداد NTFS Permissions بـ Script

function Set-FolderPermissions {
    param($FolderPath, $GroupName, $Permission)
    
    $acl = Get-Acl $FolderPath
    $rule = New-Object System.Security.AccessControl.FileSystemAccessRule(
        $GroupName, $Permission, "ContainerInherit,ObjectInherit", "None", "Allow"
    )
    $acl.SetAccessRule($rule)
    Set-Acl -Path $FolderPath -AclObject $acl
    Write-Host "Set $Permission for $GroupName on $FolderPath"
}

Set-FolderPermissions "D:\Company\HR" "GG_HR_Staff" "Modify"
Set-FolderPermissions "D:\Company\IT" "GG_IT_Staff" "Modify"
Set-FolderPermissions "D:\Company\Shared" "Domain Users" "ReadAndExecute"
Set-FolderPermissions "D:\Company\Management" "GG_Managers" "FullControl"

# عرض NTFS Permissions
(Get-Acl "D:\Company\HR").Access | Select IdentityReference, FileSystemRights, AccessControlType

# عرض Share Permissions
Get-SmbShareAccess -Name "HR$"
