User Groups فى Active Directory

شرح نظري وتطبيق عملي لإدارة Windows Server.

العودة إلى فهرس الدروس

الـ Groups بتساعدك تدير الصلاحيات بكفاءة. بدل ما تدى كل User صلاحية لوحده، بتحطهم فى Group وبتدى الـ Group الصلاحية.

أنواع الـ Groups

من حيث النوع (Group Type)

  • Security Groups: بتستخدم للصلاحيات والـ Permissions - الأكثر شيوعاً
  • Distribution Groups: بتستخدم للبريد الإلكترونى (Mailing Lists) - مش ليها صلاحيات

من حيث النطاق (Group Scope)

النطاق الأعضاء الاستخدام الـ AGDLP
Global Users من نفس الـ Domain تجميع Users بنفس الوظيفة G
Domain Local Users وـ Groups من أى Domain تحديد الصلاحيات على Resources DL
Universal Users وـ Groups من أى Domain فى الـ Forest الشبكات الكبيرة متعددة الـ Domains U

AGDLP - Best Practice

الـ AGDLP هى أفضل ممارسة لإدارة الصلاحيات:

  • A: Accounts (المستخدمين)
  • G: Global Groups (تجميع المستخدمين)
  • DL: Domain Local Groups (تحديد الصلاحية)
  • P: Permissions (الصلاحية الفعلية)
مثال:
- Users (A): Ahmed, Sara, Mohamed (كلهم فى IT)
- Global Group (G): GG_IT_Staff (بيضم Users الـ IT)
- Domain Local (DL): DL_Shared_ReadWrite (صلاحية Read/Write على الـ Shared Folder)
- Permission (P): Read/Write على مجلد الـ Shared

الخطوات:
1. حط Ahmed, Sara, Mohamed فى GG_IT_Staff
2. حط GG_IT_Staff فى DL_Shared_ReadWrite
3. دّى DL_Shared_ReadWrite صلاحية Read/Write على المجلد

إنشاء وإدارة Groups

# إنشاء Group
New-ADGroup -Name "GG_IT_Staff" -GroupScope Global -GroupCategory Security -Path "OU=Groups,DC=networkat,DC=local"

# إضافة Members
Add-ADGroupMember -Identity "GG_IT_Staff" -Members "ahmed.ali","fatima.hassan"

# عرض Members
Get-ADGroupMember -Identity "GG_IT_Staff" | Select Name

# إزالة Member
Remove-ADGroupMember -Identity "GG_IT_Staff" -Members "ahmed.ali" -Confirm:$false

# إضافة Group لـ Group
Add-ADGroupMember -Identity "DL_Shared_ReadWrite" -Members "GG_IT_Staff"

التطبيق العملى - Groups

تمرين 1: AGDLP كامل

# الـ Global Groups (حسب الوظيفة)
New-ADGroup -Name "GG_IT_Staff" -GroupScope Global -GroupCategory Security -Path "OU=Groups,DC=networkat,DC=local"
New-ADGroup -Name "GG_HR_Staff" -GroupScope Global -GroupCategory Security -Path "OU=Groups,DC=networkat,DC=local"
New-ADGroup -Name "GG_Managers" -GroupScope Global -GroupCategory Security -Path "OU=Groups,DC=networkat,DC=local"

# الـ Domain Local Groups (حسب الـ Resource)
New-ADGroup -Name "DL_IT_Share_RW" -GroupScope DomainLocal -GroupCategory Security -Path "OU=Groups,DC=networkat,DC=local"
New-ADGroup -Name "DL_HR_Share_RW" -GroupScope DomainLocal -GroupCategory Security -Path "OU=Groups,DC=networkat,DC=local"
New-ADGroup -Name "DL_Shared_Read" -GroupScope DomainLocal -GroupCategory Security -Path "OU=Groups,DC=networkat,DC=local"

# إضافة Users للـ Global Groups
Add-ADGroupMember -Identity "GG_IT_Staff" -Members "ahmed.ali","fatima.hassan"
Add-ADGroupMember -Identity "GG_HR_Staff" -Members "sara.omar","omar.ibrahim"

# إضافة Global Groups للـ Domain Local Groups
Add-ADGroupMember -Identity "DL_IT_Share_RW" -Members "GG_IT_Staff"
Add-ADGroupMember -Identity "DL_HR_Share_RW" -Members "GG_HR_Staff"
Add-ADGroupMember -Identity "DL_Shared_Read" -Members "GG_IT_Staff","GG_HR_Staff"

تمرين 2: التحقق

# عرض Members
Get-ADGroupMember -Identity "GG_IT_Staff" -Recursive | Select Name, ObjectClass

# عرض الـ Groups اللى User فيها
(Get-ADUser -Identity "ahmed.ali" -Properties MemberOf).MemberOf

# عرض Groups متداخلة
Get-ADGroupMember -Identity "DL_IT_Share_RW" | Select Name, ObjectClass
